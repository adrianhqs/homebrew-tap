# Homebrew tap for Ratio

[Ratio](https://useratio.app) is a notepad calculator for Mac, Windows and Linux: write sums like a note and
see the answer as you type, with live currencies, units, dates and time zones.

```sh
brew install adrianhqs/tap/ratio
```

This also links the `ratio` command for the Terminal. The app updates itself; `brew upgrade` works too.
